# 情绪气象台 · 会呼吸的日记

一个把情绪比喻成天气的轻量记录网页。选一个天气，写一句话，丢一颗胶囊。

## 功能

- **登录页**：输入用户名与密码（各最多 20 字）即可进入，已登录无需重复登录
- **首页（气象台）**：今日情绪天气、近 7 天天气轨迹、一键记录入口
- **记录页**：三步记录——选天气（6 种）→ 写一句话（最多 30 字）→ 选地点标签
- **查看页**：沉浸式左右拖拽翻卡，浏览历史记录（桌面支持惯性滑动、箭头与键盘）
- **个人页**：欢迎回来过渡页、上传头像、修改用户名

纯前端实现，数据保存在浏览器本地（localStorage），无需后端。

## 本地运行

任意静态文件服务器即可，例如：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 目录结构

```text
index.html           页面入口
css/styles.css       设计系统与样式
js/data.js           数据层（localStorage）
js/app.js            页面与交互逻辑
assets/weather/      6 种情绪天气图片
```

## 素材与文案说明

- 6 张天气图片取自项目「天气」文件夹，开心=日出、emo=迷雾、焦虑=闪电、平静=极光、疲惫=雨、期待=朝霞
- 全站文案与动效规范见 `文案.md`、`动画.md`、`ui补充说明.md`
